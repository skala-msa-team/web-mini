## Main Flow

```text
웹 최초 진입
  -> 홈 화면
  -> 로그인 여부 확인
  -> 커뮤니티 탐색
  -> 게시글 상세
  -> 재판 신청
  -> A측 상황 입력
  -> B측 상황 입력
  -> AI 변론문 미리보기
  -> Live 재판 시작
  -> 채팅·투표·AI 발언
  -> 재판 결과 화면
  -> AI 판결 결과와 대중 투표 결과 확인
```
